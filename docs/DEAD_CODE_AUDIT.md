## Summary

Only two directories/files were deleted this pass (`tests/benchmark/`, `tests/unit/test_llm.py`), both explicitly pre-documented as dead by the codebase's own README and already non-functional (import errors). One stale/insecure hardcoded default was fixed without touching any algorithm or scientific-behavior code. One genuine duplication (`backend/llm/provider.py` vs `backend/api/main.py:_default_provider()`) was identified but left untouched and flagged, since resolving it would require changing test code and is a design decision, not a cleanup action.
